# 投稿前自查清单（40 项）

按顺序逐项过。每项给出「怎么查」和「不合规怎么办」。诊断模式下只报不合规项，不要逐条刷屏。

## A. 语言与语气（1–10）

| # | 检查 | 怎么查 | 不合规的改法 |
|---|---|---|---|
| 1 | 平均句长 18–24 词 | 抽 3 段数词 | >28 拆句 |
| 2 | 长句（>40 词）占比 ≤ 8% | 通读标记 | 拆成两句，条件提独立句 |
| 3 | 短句（<15 词）占比 ≥ 25% | 通读 | 把两三个短句合并一句 |
| 4 | 第一人称 ≤ 3 次/100 句 | 搜 `\bwe\b|\bour\b` | 改被动或 `It can be observed` |
| 5 | 被动密度：整篇 1.5–3.0 / 100 词（单节可到 4.0） | 抽段统计 | 过少→改被动；过多→改主动 |
| 6 | 段首连接词覆盖率 20–30% | 看段首 | 补 `Moreover,/However,/Therefore,` |
| 7 | 同段不混用 `Therefore/Thus/Hence` | 搜段内 | 统一为 `Therefore,` |
| 8 | `But,` 每段 ≤ 1 次 | 搜 `But,` | 多出的改 `However,` 或删 |
| 9 | 无 `obviously / clearly / very / a lot of` | 搜词 | 删或改 `it can be observed` |
| 10 | 时态一致（事实现在时、文献过去时） | 抽查 | 统一 |

|---|---|---|---|

| 12 | 每个综述段有转折收尾 | 看段末 | 补 `But, ...` |
| 13 | 贡献 3 条且类型互补 | 看列表 | 改成「方法/保证/适用性」 |

## D. 符号与公式（23–31）

| # | 检查 | 怎么查 | 不合规的改法 |
|---|---|---|---|
| 23 | 每个符号先定义后使用 | 顺序通读 | 补 `Let/Denote/where` |
| 24 | 集合花体、向量粗体、算子 `\mathrm` | 搜 `\mathcal/\mathbf/\mathrm` | 统一 |
| 25 | 范数统一 `\|·\|` | 搜 `||`、`\mid` | 替换 |
| 26 | 公式引用方式篇内统一（`\eqref` / 文本 `(n)` / `\ref{eq:}` 三选一） | 搜三种写法 | 按原稿流派统一，不混用 |
| 27 | 多行共号用 `equation+aligned` | 看公式 | 重构 |
| 28 | 复合下标与全文一致 | 抽 10 处 | 统一平铺/嵌套 |
| 29 | 单位正体 + 窄空格 | 搜 `kg`、`m/s` | `\,\mathrm{kg}` |
| 30 | 同一字母不表示两个含义 | 符号表核对 | 换符号 |
| 31 | 长行内公式不超宽 | 看编译日志 | `\{ \}` + `\allowbreak` |

## H. 个人硬规则（linter 可自动检查，优先级最高）

| # | 检查 | 怎么查 | 不合规的改法 |
|---|---|---|---|
| 41 | 无 `which` | `style_lint.py` / grep | 分词状语、`that` 从句、或拆句 |
| 42 | 无 `while` | 同上 | 拆分并列/转折，另起一句 |
| 43 | 无 `i.e.` / `namely` | 同上 | `that is` / 直接改写定义 |
| 44 | 无 `due to` | 同上 | `owing to` / `because of` / `as a result of` |
| 45 | 无 `associated with` / `corresponds` | 同上 | `related to` / `derived for` / `matches` |
| 46 | 无分号 `;` | 同上 | 拆句，或改 `and` / `thereby` |
| 47 | 无第一人称 we/our/us | 同上 | 被动或无生命主语 |
| 48 | 单句 ≤ 45 词 | linter 的 sentence 检查 | 拆句，保留条件与引用范围 |

**硬规则与组内风格的冲突**：语料中的 `which yields`、`due to its applications`、分号并句等属历史用法，命中即按 `language.md` 重构。交付时在「保留项说明」里记录这类让步。

## 评分口径（诊断时用）

| 维度 | 权重 | 判定 |
|---|---|---|
| 结构（11–16） | 30% | 缺 move / 缺转折句 = 不通过 |
| 语言（1–10） | 25% | 三项以上超标 = 不通过 |
| 符号公式（23–31） | 20% | 定义缺失或引用方式错 = 不通过 |
| 术语（17–22） | 15% | 术语不一致 = 不通过 |
| 图表引用数值（32–40） | 10% | 引用缺失/数值冲突 = 不通过 |

**报告格式**：`通过 / 需修改（n 项）/ 不通过`，并列出**逐项定位**（文件 + 段落 + 原句），不要给笼统评价。
