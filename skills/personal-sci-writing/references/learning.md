# Learning Mode

Inventory newly supplied files, authorship, publication status, source format and versions. Use only authorized material. Prefer LaTeX source when available and check PDF column order otherwise.

Preserve original evidence locally with source anchors. Exclude bibliography, metadata, equations, code and quotations from language statistics. Group versions into one paper vote. Distinguish topic vocabulary from rhetorical style and give independent papers equal weight unless instructed otherwise.

Analyze Abstract sentences, Introduction paragraphs, contribution argument order and representative language from other sections. Record counterexamples and evidence limitations. Do not infer stable personal preferences from a single new paper.

Retain an independent test paper before deriving new rules. Produce a change report containing the old rule, proposed rule, supporting/counter evidence, independent-paper support count and likely effect. Do not overwrite hard lexical rules without an explicit user instruction. Run relevant tests after an accepted update.

Keep new private paper evidence outside the public distribution unless publication of that material is explicitly authorized. The public templates can be updated without uploading source manuscripts.
